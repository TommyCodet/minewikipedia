# Tränke Übersicht
Alle Tränke brauchst du einen Braustand + Netherwarze.

## Basis-Rezept
1. Wasserflasche + Netherwarze = Seltsamer Trank
2. Seltsamer Trank + Zutat = Trank

| Trank | Zutat | Effekt |
|---|---|---|
| Heilung | Glitzernde Melone | Heilt sofort |
| Stärke | Lohenpulver | Mehr Schaden |
| Schnelligkeit | Zucker | Schneller laufen |
| Regeneration | Ghast-Träne | Heilt über Zeit |
| Nachtsicht | Goldene Karotte | Im Dunkeln sehen |
| Feuerresistenz | Magma-Creme | Kein Feuerschaden |
| Unsichtbarkeit | Fermentiertes Spinnenauge | Unsichtbar |

## Verlängern / Verstärken
- **Redstone:** Länger (8:00 statt 3:00)
- **Glowstone:** Stärker (Stufe II, aber kürzer)
- **Schwarzpulver:** Wurftrank
- **Drachenatem:** Verweiltrank
